# AdCraft

AdCraft is an automated, AI-powered marketing tool that transforms standard e-commerce product links into fully polished Meta Ad campaign videos.

## Overview

The core user journey follows a seamless pipeline:
1. **Product Link**: Input a product link (e.g., from Myntra, Amazon).
2. **Scraping**: Automatically extract high-resolution product images, pricing, and metadata.
3. **AI Style Generation**: Generate stylized lifestyle or model images (e.g., Festive, Casual, Night) from the raw product images.
4. **Video Generation**: Select a "hero" style to generate a 9:16 vertical video tailored for social media.
5. **Publishing**: Optionally publish the resulting video directly as a Meta Ad.
